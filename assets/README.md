# Assets

Place the following files here before running:

- `lobby-loop.mp4` — looping video for the LOBBY state
- `ident.mp4` — branded cinema opening (~30s) for the IDENT state
- `feature-presentation.mp4` — "And Now Our Feature Presentation" bumper for the BUMPER state
- `yt-dlp.exe` (Windows) / `yt-dlp` (macOS/Linux) — yt-dlp binary

The yt-dlp binary path can be overridden in storage at `settings.ytdlpBinaryPath`.
